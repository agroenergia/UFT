Como funciona no GitHub Pages: como o site é hospedado de forma estática no GitHub Pages, cada navegador registra seus próprios acessos em armazenamento local (rigoratlas_visits_v1) e permite exportar tudo em Bloco de Notas (.txt) ou .json.

Opcional: Sincronizar acessos de outros computadores na nuvem (Google Planilhas / Drive)

Para receber automaticamente os acessos de qualquer visitante da internet em uma única planilha do seu Google Drive, crie um Google Apps Script Web App com o código abaixo, publique como “Qualquer pessoa” e cole a URL gerada aqui neste navegador:

function doPost(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sh = ss.getSheetByName("Visitas") || ss.insertSheet("Visitas");
  if (sh.getLastRow() === 0) sh.appendRow(["Data/Hora","Pagina","Dispositivo","Navegador","Resolucao","Origem","Acoes"]);
  var d = JSON.parse(e.postData.contents);
  sh.appendRow([d.dataHoraBR, d.paginaInicial, d.dispositivo, d.navegadorSistema, d.resolucao, d.origem, (d.acoes||[]).join(" | ")]);
  return ContentService.createTextOutput(JSON.stringify({ok:true})).setMimeType(ContentService.MimeType.JSON);
}
